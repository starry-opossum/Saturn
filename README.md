# Saturn
一个很简单vibe coding试验品——“Saturn”手势交互式 3D 粒子系统：基于 MediaPipe 手势识别与 Three.js 着色器，实现了实时开普勒运动的土星星云，支持 20 万粒子的高性能渲染与“捏合-混沌”触觉反馈。

## 🖐️ 手势操作说明

| 手势                         | 功能描述                         |
| --------------------------- | ------------------------------- |
| 🤚 **手掌左右/上下移动**       | 控制星云的 360° 旋转视角          |
| ✌️ **拇指与食指捏合/张开**      | 控制星环的缩放与“混沌炸裂”效果     |

## ✨ 技术亮点

- **高性能粒子系统**：使用 **GLSL 着色器** 在 GPU 中完成 20 万粒子的轨道计算，实现流畅的 60 帧渲染。
- **物理模拟**：粒子的角速度遵循**开普勒定律**（外环转速较慢），并实现了“小暗大亮”的物理亮度映射。
- **非接触交互**：基于 **MediaPipe** 实现 21 个手部关键点的实时追踪，将捏合距离连续映射为粒子的“缩放”与“混沌”参数。

## 🛠️ 技术栈

- Three.js (r128) —— 3D 渲染引擎
- MediaPipe Hands —— 手势识别与追踪
- GLSL —— 自定义顶点/片段着色器
- HTML5 / CSS3 / JavaScript (ES6)
